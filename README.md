# AoU Multi-omics analysis

## Overview:
This repository is dedicated to the analysis of the multi-omics data generated as part of the All of Us Research Consortium (https://www.researchallofus.org). As a brief overview of the data, for 10,000 individuals from AoU deep multiomic data has been collected. This consists of blood RNA-seq (Watchmaker transcriptomics https://www.watchmakergenomics.com/rna-ngs-solutions/rna-with-polaris.html) and plasma proteomiecs (Olink Explore HT). In addition to these omic profiles there is all long read genome data, that data is described elsewhere. As part of the multi-omic cohort, long-read genome data has also been generated, that data is described elsewhere.
